# Дизайн: SQL-фильтрация и пагинация

**Статус:** реализован в `TASK-0008`.

Список задач должен фильтроваться в SQLite по статусу, типу и тексту, а не загружать весь снимок в память. Для стабильной пагинации используется cursor — последний возвращённый `TASK-xxxx`; следующая страница выбирает только записи с меньшим ID и сохраняет сортировку по убыванию.

Публичный API сохраняет обратную совместимость: `cursor` необязателен, `limit` остаётся 1..500. Индекс типа добавляется миграцией схемы.
