# Дизайн: усиленная диагностика validate

**Статус:** реализован в `TASK-0010`.

`health_check` остаётся read-only и возвращает стабильные коды проблем. Помимо SQLite integrity и последовательности событий он сверяет JSON-снимок с колонками таблицы, допустимость статуса, валидность payload и отсутствие событий для неизвестных задач. Таблица `operations` проверяется на корректный JSON результата и непустой fingerprint.
