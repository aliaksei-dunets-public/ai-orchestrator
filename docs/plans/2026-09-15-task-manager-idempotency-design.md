# Дизайн: идемпотентность мутаций Task Manager

**Статус:** реализован в `TASK-0006`.

## Решение

В SQLite добавляется таблица `operations`. Она хранит `operation_id`, отпечаток входной операции, JSON-результат и время записи. Создание задачи и ключевые lifecycle-мутации проверяют журнал внутри той же транзакции, что и snapshot/event.

Повтор с тем же отпечатком возвращает сохранённый результат без нового события. Повтор с другим отпечатком получает `operation_conflict`. Публичный API остаётся совместимым: `operation_id` — необязательный keyword-параметр.

Решение не является очередью сообщений и не переносит состояние Graph Runtime в Task Manager.
