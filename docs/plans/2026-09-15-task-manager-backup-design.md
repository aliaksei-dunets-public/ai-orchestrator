# Дизайн: backup/export/restore Task Manager

**Статус:** реализован в `TASK-0007`.

## Решение

Task Manager получает безопасные операции экспорта и резервной копии через публичный сервисный API. Экспорт — детерминированный JSON без секретов; backup — консистентная копия SQLite через `Connection.backup`; restore сначала проверяет копию во временном расположении и заменяет рабочую БД только после успешной диагностики.

## Границы

- операции не меняют lifecycle задач;
- restore не принимает путь за пределами явно переданного пользователем файла;
- перед заменой текущая БД сохраняется как `.pre-restore`;
- CLI только вызывает сервисный API.

## Проверки

Экспорт, backup/restore, повреждённая копия и отсутствие изменения исходной БД покрываются тестами.
