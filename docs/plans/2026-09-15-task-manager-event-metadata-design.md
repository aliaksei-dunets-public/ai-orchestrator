# Дизайн: метаданные событий

**Статус:** реализован в `TASK-0009`.

Каждое событие получает необязательный контекст происхождения: `actor_ref`, `source`, `correlation_id`, `run_ref`. Поля nullable для совместимости со старыми строками. Контекст записывается в той же транзакции, что и снимок задачи; при `operation_id` correlation по умолчанию равен идентификатору операции.

Чтение истории возвращает поля на верхнем уровне события. Неизвестные ключи контекста отклоняются как ошибка валидации.
