# Дизайн: отказоустойчивые тесты Task Manager

**Статус:** реализован в `TASK-0011`.

Тесты фиксируют границы транзакций: конкурентные повторы одного `operation_id` дают один результат, ошибка guard не меняет snapshot и историю, повреждённый backup не заменяет рабочую БД. Сценарии используют публичный API; прямой SQLite применяется только для контролируемого внесения повреждения в fixture.
