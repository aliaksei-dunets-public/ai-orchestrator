# Граф для агента в реальном времени

**Статус:** подтверждено пользователем, 2026-09-15. Решение о первом срезе; код runtime отсутствует.

## Решение

Один агент в одной сессии последовательно выполняет узлы. Граф задаёт входы, проверяет структурированные результаты и выбирает переходы. При вопросе пользователю процесс ждёт ответа в той же сессии.

Состояние запуска находится в памяти. Задача остаётся в SQLite автономного Task Manager. Specification и Plan остаются файлами. Существующие task-claim и guards не меняются.

## Отклонённый объём

Проект отдельной SQLite runtime, индекса продолжений, runtime-lease и поколений относится к отдельной [будущей функции координации](../architecture/runtime-coordination.md). Пользователь уточнил работу агента в реальном времени; эта функция сейчас не реализуется.

Контрольные точки между сессиями можно добавить отдельно. Автоматическое восстановление после сбоя, параллельные ветви и распределённая координация не являются требованиями первого среза.

## Документы и следующий шаг

Сверить [Workflow Run](../architecture/workflow-run.md) и [паузу](../architecture/workflow-pause-resume.md) с существующими материалами `docs/graph/` и `docs/development/`; прежние проекты отметить историческими. Реализация должна следовать этим контрактам, а не вводить параллельную схему.

Не вводить блокировочную инфраструктуру для решения существующего ограничения API возврата от устаревшего ожидания к подготовке: этот переход следует согласовать отдельно.

## Проверки

Проверить локальные ссылки, статусы связанных документов и diff. Код и базы не менять; функциональные тесты runtime появятся вместе с реализацией.
