# Миграция на 1.0

[English version](1.0.md)

Поддерживается переход с прототипов specification 0.4 / Task Layer 0.3 на
schema version 1. Реестры, Task Context, review results, approvals, memory и
profile contracts совместимы в пределах ветки 1.x. Operational `tasks.json`
остаётся локальным и не перезаписывается managed installation.

Для отката восстановите прежний core и tracked файлы проекта из Git. Не
изменяйте `tasks.json` вручную во время работы Task Manager.
