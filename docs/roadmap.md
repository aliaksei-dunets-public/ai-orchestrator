# План миграции Orchestrator

Минимальные Graph Runtime, Artifact Repository и Preparation Workflow реализованы; полного графового фреймворка исполнения пока нет. Документы в этом каталоге — проектные материалы; их статус указан в каждом файле. Разработка идёт последовательно. Этап завершён только тогда, когда его контракты, код, тесты, русскоязычная документация и необходимые гайды согласованы.

1. **Граница репозитория (выполнено):** сохранить прежний продукт, старое локальное состояние и релизы в `obsolete/`; перенести проектные документы нового подхода в `docs/`; обновить инструкции в корне и проверить сохранность файлов и ссылок.
2. **Первичная настройка проекта (первый срез реализован):** отдельный пакет Onboarding содержит безопасный протокол preview/apply для внешнего проекта и self-hosting. Сборка общего пакета ядра, проверка его установки и обновления остаются будущими работами. Действующий контракт: [первичная настройка](architecture/onboarding.md), [инструкция](guides/onboarding.md).
3. **Согласование и первый runtime-срез (выполнено):** [граница хранения](architecture/state-and-storage.md), [граф агента в реальном времени](architecture/workflow-run.md), [пауза в сессии](architecture/workflow-pause-resume.md) и [пользовательский guide](guides/workflow-runtime.md) согласованы. Реализованы первый входной срез [Request Router → Task Creator](guides/request-flow.md), core in-memory runtime одной сессии (TASK-0003), предметные тесты и документация (TASK-0004 завершена). Состояние процесса — в памяти. Возможная [будущая координация нескольких запусков](architecture/runtime-coordination.md) вынесена отдельно и сейчас не реализуется. Интеграционное связывание с Task Manager и Artifact Repository относится к следующим этапам.
4. **Детерминированная основа (Task Manager Service — первый срез):** отдельный устанавливаемый пакет содержит SQLite-хранилище задач, события, защищённые переходы, версионируемый реестр миграций схемы, идемпотентность, backup/export/restore, архивацию с retention и локальную панель по [действующему контракту](architecture/task-manager.md). Дополнительная TASK-0023 разрешена пользователем для надёжности, скорости диагностики и агентского CLI; [результаты](reports/2026-09-16-task-manager-hardening.md) отделены от дальнейшей реализации графа. TASK-0024 разрешена для внутреннего разделения пакета с сохранением API и схемы; [результаты разделения](reports/2026-09-17-task-manager-modularization.md) не означают реализацию runtime. Artifact Repository и минимальный in-memory движок переходов уже реализованы; подготовка и исполнение развиваются следующими срезами.
5. **Подготовка задачи:** Artifact Repository v1 реализован, прошёл независимый Luna High аудит с исправлениями и принят в TASK-0014 (completed, version 21). TASK-0015 реализует минимальные контекст, анализ, планирование, проверку плана и устойчивую границу `ready`; принята пользователем и завершена (version 18). Структурированная карточка Task Manager является каноническим определением задачи. [Контракт](architecture/preparation-workflow.md), [guide](guides/preparation-workflow.md), [отчёт](reports/2026-09-17-preparation-workflow.md).
6. **Исполнение задачи:** TASK-0016 реализует preflight, claim/lease и work units; TASK-0017 — ревью, тесты, документацию, финальную проверку и приёмку пользователем.
7. **Знания и интеграции:** после TASK-0017 согласовать и реализовать Project Knowledge Map (TASK-0019–0020), затем собрать устанавливаемое ядро (TASK-0021). Внешний Task Tracker Adapter (TASK-0018) отложен на будущее и не блокирует локальный v1.
8. **Сквозная проверка:** TASK-0022 выполняет сценарные, восстановительные, конкурентные, защитные и межплатформенные тесты локального v1 и публикует свидетельства готовности релиза.

Полная карта зависимостей и источников: [backlog развития v1](plans/2026-09-16-orchestrator-roadmap-backlog-design.md).

На каждом этапе фиксируй выполненные работы, результаты проверок и исправления документации. Не переноси старый код неявно: нужный навык, идея или контракт из `obsolete/` должны быть осознанно адаптированы и проверены на соответствие новым контрактам.
