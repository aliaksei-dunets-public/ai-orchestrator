# Roadmap

Version 1.0 completes phases 0–23 from the normative roadmap. Version 1.1 adds Phase 24 selective skill distribution: system and bundled skills form the default projection, optional skills require approval, and project-owned skills remain independent from shipped sources. Future work is evidence-driven: interprocess Task Registry locking remains an optional feature for a demonstrated multi-writer requirement, and additional platform/technology adapters must pass the same contracts and acceptance matrix.

Google Antigravity, GitHub Copilot VS Code and Claude VS Code profiles remain experimental until native smoke evidence satisfies DEC-005; this promotion work does not change the stable Core contract.
