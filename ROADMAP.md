# Roadmap

Version 1.0 completes phases 0–23 from the normative roadmap. Version 1.1 adds Phase 24 selective skill distribution. Version 1.2 completes Phase 25: target-owned canonical Project Memory and Knowledge Graph stores, source-authority promotion, additive ontology, deterministic bounded retrieval, onboarding/migration, JSON CLI, workflow routing, Health and security gates. Future work is evidence-driven: interprocess Task Registry locking remains optional for a demonstrated multi-writer requirement, and additional platform/technology adapters must pass the same contracts and acceptance matrix.

Google Antigravity, GitHub Copilot VS Code and Claude VS Code profiles remain experimental until native smoke evidence satisfies DEC-005; this promotion work does not change the stable Core contract.
