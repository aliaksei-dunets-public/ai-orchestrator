# Спецификация TASK-0009

Расширить события Task Manager метаданными происхождения (`actor_ref`, `source`, `correlation_id`, `run_ref`) и публичным `event_context` для ключевых мутаций. Выполнить миграцию существующей SQLite без потери событий; старые записи читаются с `null`.

Критерии: поля сохраняются атомарно; история возвращает их; operation_id автоматически связывается как correlation_id, если контекст его не переопределяет; неизвестные поля отклоняются.
