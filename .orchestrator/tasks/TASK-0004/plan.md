# План TASK-0004: проверить и документировать Workflow Runtime

## Цель

Закрепить фактическое поведение принятого минимального in-memory Graph Runtime v1 предметными тестами, пользовательским гайдом и согласованными статусами проектной документации.

## Объём

1. Проверить реализацию `orchestrator.workflow_runtime` относительно контрактов Graph Runtime v1 и критериев TASK-0004.
2. Проверить и при необходимости дополнить тесты успешного шага, terminal-состояний, `needs_input`/`resume`, `blocked`/`resume_blocked`, отмены и структурированных ошибок.
3. Добавить отдельный русскоязычный пользовательский гайд запуска runtime с минимальным примером, границами v1 и правилом интеграции с Task Manager.
4. Устранить устаревшие утверждения в навигации и связанных архитектурных материалах: core runtime реализован, а автоматическое связывание, Artifact Repository и многосессионное восстановление остаются отдельными этапами.
5. Запустить корневые, Task Manager и Onboarding тесты, compileall, проверку markdown-ссылок/diff и live `orchestrator-tasks validate`.

## Ограничения

- Не добавлять интеграцию Graph Runtime с Task Manager в этот этап.
- Не добавлять Executor Loop, persistent checkpoints или новую runtime-базу.
- Состояние Task Manager изменять только через публичный CLI/API; SQLite напрямую не редактировать.
- Сохранить текущую схему Task Manager и публичные импорты.

- Актуализированные `docs/project-status.md`, `docs/roadmap.md`, навигационный `docs/README.md` и связанные архитектурные ссылки.
- Регрессионные тесты и отчёт проверки TASK-0004.
