# Спецификация TASK-0011

Добавить отказоустойчивые тесты Task Manager для конкурентных повторов, rollback транзакций, миграций и backup/restore. При любой ошибке состояние задачи и последовательность событий должны оставаться неизменными.

Критерии: тестируется минимум конкурентный operation_id, неуспешный переход и повреждённая резервная копия; тесты стабильны на Windows и Linux.
