# Спецификация TASK-0007

Добавить в изолированный Task Manager публичные операции `export_state`, `backup` и `restore` и соответствующие CLI-команды. Экспорт должен быть читаемым и детерминированным, backup — консистентным снимком SQLite, restore — атомарной заменой после проверки схемы и `health_check`. Ошибка восстановления не должна повреждать текущую базу.

Критерии: операции доступны через API и CLI; restore отбрасывает неподдерживаемую/повреждённую копию; исходное состояние сохраняется до успешной проверки; тесты проверяют round-trip и отказ.
