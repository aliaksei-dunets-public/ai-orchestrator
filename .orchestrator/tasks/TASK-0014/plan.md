# План TASK-0014: Artifact Repository v1

## Цель

Реализовать независимый файловый репозиторий артефактов Orchestrator с устойчивой ссылкой, ролью, версией и SHA-256, не превращая его в хранилище состояния задач или запусков.

## Объём

1. Добавить `orchestrator.artifact_repository` с публичными `ArtifactRepository`, `ArtifactRecord`, `StoredArtifact` и структурированной `ArtifactError`.
2. Хранить данные под `.orchestrator/artifacts/` с JSON-манифестом и бинарным payload; использовать атомарные временные файлы и отказ от перезаписи существующей версии.
3. Реализовать запись bytes/text и canonical JSON, чтение с повторной проверкой размера и SHA-256, list/verify и строгую валидацию идентификаторов и путей.
4. Экспортировать API из `orchestrator`, добавить предметные тесты и проверить отсутствие зависимости от Task Manager/SQLite.
5. Обновить русскоязычный контракт хранения, guide интеграции, project status, roadmap и worklog.

## Границы

- Репозиторий не хранит lifecycle задачи, события, claims или WorkflowRun.
- Task Manager получает только ссылки и метаданные через свой публичный API; прямой SQL запрещён.
- Удаление, retention, внешнее object storage и многопроцессная координация не входят в v1.
- `obsolete/` не импортируется и не запускается.

## Проверки

Тесты должны покрывать успешную запись/чтение, версии и роли, canonical JSON, hash tampering, traversal, отказ от случайной перезаписи, отсутствующий артефакт и независимость от SQLite. Полный набор корневых, Task Manager и Onboarding проверяется перед готовностью задачи.
