# Спецификация TASK-0008

Добавить SQL-фильтры `status`, `type`, `query` и cursor-пагинацию в `list_tasks`, сохранив детерминированный порядок `id DESC`. Запрос не должен загружать в память все задачи перед фильтрацией. CLI принимает `--cursor`; веб-панель сохраняет текущую совместимость.

Критерии: фильтры комбинируются; cursor возвращает следующую страницу без дублей; неверный cursor и limit дают `validation_failed`; существующие вызовы без cursor работают как прежде.
