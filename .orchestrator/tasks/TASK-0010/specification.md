# Спецификация TASK-0010

Расширить диагностику Task Manager без изменения состояния: проверять статус, id/version/title/type снимка, JSON payload событий, orphan-события и содержимое таблицы операций. Каждая проблема имеет код и severity; успешная проверка возвращает пустой список.

Критерии: повреждения обнаруживаются до lifecycle-операций; validate ничего не исправляет; тесты покрывают минимум три класса повреждений.
