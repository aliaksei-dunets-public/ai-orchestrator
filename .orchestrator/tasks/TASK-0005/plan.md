# План: миграции схемы SQLite Task Manager

1. Вынести SQL базовой схемы в функцию миграции `0 → 1` и определить текущую версию.
2. Добавить общий обработчик последовательных миграций с `BEGIN IMMEDIATE`, проверкой версии и обновлением `PRAGMA user_version`.
3. Сохранить существующие snapshot/event SQL-контракты и поведение `TaskManagerService`.
4. Добавить тесты свежей базы, совместимости версии 1, отказа неподдерживаемой версии и сохранности истории.
5. Обновить контракт/README и запустить Task Manager, корневые и Onboarding тесты.
