# Спецификация: миграции схемы SQLite Task Manager

## Цель

Сделать эволюцию локальной SQLite-схемы Task Manager версионируемой и безопасной для существующих проектов.

## Объём

- Реестр упорядоченных миграций внутри `SQLiteTaskRepository`.
- Базовая миграция `0 → 1` для таблиц `meta`, `tasks`, `events` и индекса статуса.
- Проверка поддерживаемой версии до изменения базы.
- Транзакционное применение миграций.
- Тесты совместимости, отказа будущей версии и сохранности истории.

## Критерии приёмки

1. Свежая база и база с `user_version=0` поднимаются до текущей версии через `TaskManagerService`.
2. Существующая база версии 1 открывается без потери задач и событий.
3. Неподдерживаемая версия отклоняется диагностируемой `TaskError` до записи.
4. Реестр и порядок миграций документированы; публичная семантика сервиса не меняется.
5. Пакетные и корневые тесты проходят.
