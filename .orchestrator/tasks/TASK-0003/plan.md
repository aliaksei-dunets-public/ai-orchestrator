# План реализации TASK-0003

1. Добавить независимый модуль `orchestrator.workflow_runtime` с immutable-моделью графа и in-memory состоянием запуска.
2. Реализовать валидацию Graph/Node/NodeResult/WaitState и структурированные `RuntimeError` без зависимости от Task Manager и платформы.
3. Реализовать `create_run`, `inspect_run`, `step`, `resume`, `cancel`; один вызов `step` обрабатывает только один узел.
4. Добавить тесты на happy path, terminal outcomes, ожидание пользователя, stale wait, некорректные результаты, блокировки и изоляцию запусков.
5. Обновить действующие архитектурные документы, project-status, worklog и добавить отчёт с результатами проверок.

Ограничения: состояние только в памяти; SQLite, Executor Loop, многосессионность и автоматическое восстановление не добавляются. Task Manager изменяется только через его публичный API отдельным интеграционным адаптером, который не входит в этот срез.
