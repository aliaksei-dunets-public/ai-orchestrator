# Спецификация: идемпотентность мутаций Task Manager

## Цель

Безопасно повторять запрос после таймаута или повторной доставки без дублирования задачи, события или lifecycle-изменения.

## Критерии приёмки

1. Повтор создания с тем же `operation_id` возвращает исходную задачу.
2. Повтор ключевой мутации возвращает сохранённый snapshot без нового события.
3. Другой payload с занятым `operation_id` отклоняется кодом `operation_conflict`.
4. Журнал операции и основное изменение записываются атомарно.
5. Публичный API без `operation_id` сохраняет прежнее поведение.
