# Миграция на 1.2

[English version](1.2.md)

Версия 1.2 добавляет target-owned Project Memory и Knowledge Graph, source
authority, deterministic retrieval, onboarding и additive CLI. Схемы остаются
version 1. Перед переносом сохраните `.orchestrator/` и запустите Health Check;
graph changes применяются только после proposal approval и могут быть
откачены backup manifest.

```powershell
python -m orchestrator context --root . --mode standard
```
