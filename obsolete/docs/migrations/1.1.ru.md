# Миграция на 1.1

[English version](1.1.md)

При переходе с 1.0.x пути Task Context перемещаются в
`.orchestrator/tasks/contexts/`, а checkpoints — в
`.orchestrator/tasks/checkpoints/`. Canonical skills переходят в
`skills/system`, `skills/bundled` и `skills/optional`; потребители используют
`registries/skills.json`. Optional selection хранится в tracked
`.orchestrator/skills.json`. После обновления запустите strict Health Check и
синхронизируйте projection из core 1.1.
