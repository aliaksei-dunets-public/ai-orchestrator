# Previous AI Orchestrator

This directory contains the previous orchestrator's tracked source, architecture, code, skills, tests, configuration, and user documentation. Previous local `.orchestrator/` state, generated `.agents/` skills, and `releases/` artifacts were also moved here at the user's request. They are retained for reference and selective reuse, not as active project state.

It is **not** the active implementation of the graph-based orchestrator. Paths and commands in these files refer to the previous repository layout and may not work from this directory without adaptation. New development belongs at repository root.
