# Case: Automatic Report Language Selection

The user asks in Russian:

> Audit this skill and show only important findings, changes, and metrics.

English. No explicit request asks to translate code, identifiers, schema keys,
or quotations. No language clarification is needed.

Additional override check: when the same user explicitly says `Provide the
report in Spanish`, that explicit instruction must win.
