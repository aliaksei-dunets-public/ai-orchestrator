# Code Quality Review Contract

Report only actionable findings supported by a concrete file, evidence, impact, and remediation. Blocking findings are limited to demonstrable correctness, security, compatibility, data-loss, or acceptance failures; style preferences are advisory.

When an isolated reviewer or sub-agent is unavailable, review from a clean context using the baseline, raw diff, and test evidence, and record `same-agent-clean-context` as the reviewer mode.
